# HollowKraft

**HollowKraft (HK4)** es la siguiente edición del servidor de la comunidad **Vasijas de Hallownest**, para **Minecraft 26.x**. El proyecto está actualmente **en desarrollo**.

## ¿Qué es HollowKraft?

HollowKraft comienza como un servidor de supervivencia normal: un mundo comunitario a largo plazo donde los jugadores construyen, exploran y juegan juntos. Todo lo demás sigue en definición, y esta página crecerá conforme el proyecto tome forma.

## Java y Bedrock, juntos

HollowKraft tiene previsto recibir a jugadores de Java y de Bedrock en el mismo mundo, y **no se necesitan mods para jugar**. El servidor apunta a versiones recientes de Minecraft y también admitirá jugadores de versiones anteriores cuando sea posible.

- **Jugadores de Java**: experiencia completa.
- **Jugadores de Bedrock**: bienvenidos también, con un conjunto de funciones más limitado en su plataforma.

Un mod opcional de cliente para jugadores de Java está en desarrollo: mejora la interfaz con animaciones e iconos personalizados. Instalarlo nunca es obligatorio.

## Estado

HollowKraft está en desarrollo. Todavía no hay fecha de salida; los anuncios se compartirán conforme avance el proyecto.
