# HollowKraft

**HollowKraft (HK4)** es la siguiente edición del servidor de la comunidad **Vasijas de Hallownest**, para **Minecraft 26.x**. El proyecto está actualmente **en desarrollo**.

## ¿Qué es HollowKraft?

HollowKraft comienza como un servidor de supervivencia normal: un mundo comunitario a largo plazo donde los jugadores construyen, exploran y juegan juntos. Todo lo demás sigue en definición, y esta página crecerá conforme el proyecto tome forma.

## Java y Bedrock, juntos

HollowKraft tiene previsto recibir a jugadores de Java y de Bedrock en el mismo mundo, y **no se necesitan mods para jugar**. El servidor apunta a versiones recientes de Minecraft y también admitirá jugadores de versiones anteriores cuando sea posible.

- **Jugadores de Java**: experiencia completa.
- **Jugadores de Bedrock**: bienvenidos también, con un conjunto de funciones más limitado en su plataforma.

Un mod opcional de cliente para jugadores de Java está en desarrollo: mejora la interfaz con animaciones e iconos personalizados. Instalarlo nunca es obligatorio.

## Estado

HollowKraft está en desarrollo. Todavía no hay fecha de salida; los anuncios se compartirán conforme avance el proyecto.

### Estilo de juego

**¿HK4 es un servidor anárquico?**
No. HK4 está planeado como un mundo de supervivencia normal y comunitario, no como un
servidor anárquico ni como un servidor de festivales. La lista final de reglas está **por
anunciar**.

**¿Es PvP o PvE?**
El PvP y las protecciones aparecen como posibles diferenciadores, sin detalles. **Por
anunciar.**

**¿Estarán protegidas mis construcciones y objetos?**
La protección está planeada con Zelly's Guard, y con BlockProt Reloaded para bloques
individuales. Las reglas y los límites exactos están **por anunciar**.

**¿Será más difícil que el Minecraft vanilla?**
**Por anunciar.** No se ha publicado ningún ajuste de dificultad.

**Por anunciar.**

### Mods, versiones y plataformas

**¿Necesito mods para jugar?**
No. El servidor es totalmente jugable sin mods, tanto en Java como en Bedrock. Hay un mod
opcional de cliente para Java que mejora la interfaz con animaciones e iconos
personalizados; instalarlo nunca es obligatorio.

**¿Volverá el mod de proyectos personalizados de la edición anterior?**
El plan actual no lo incluye. El único mod en desarrollo es el mod opcional de interfaz.
Cualquier mod adicional está **por anunciar**.

**¿Pueden jugar juntos Java y Bedrock?**
Sí, en el mismo mundo. La compatibilidad de Bedrock es más limitada y tiene menos
funciones que Java.

**¿Qué versiones de Minecraft se admiten?**
HK4 apunta a versiones recientes (Minecraft 26.x) y también admite jugadores de versiones
anteriores cuando es posible.

**¿Puedo entrar desde Bedrock 1.26.52.3?**
**Por anunciar.** El acceso de Bedrock depende de la configuración de Geyser y Floodgate
del servidor; no se ha publicado una lista de versiones concretas.

**¿Qué necesito para jugar?**
Una edición de Minecraft de Java o Bedrock, una versión reciente cuando sea posible, y
ningún mod. El mod opcional de Java no es un requisito. Las recomendaciones exactas de
hardware están **por anunciar**.

### Economía y eventos

**¿Habrá economía?**
No al principio. Empieza solo cuando el dueño dé luz verde a los plugins: que funcionen y
se vean como él quiere. Si se usa, el nombre por defecto de la moneda sería "Geo",
configurable, y sus visuales necesitarían un paquete de texturas.

**¿HK4 es una edición Dedsafio? ¿Habrá eventos de temporada?**
No. HK4 es un servidor de supervivencia normal. El marco de eventos de temporada, la
"Ruleta de Sorpresas", el sistema de vidas y la zona de rescate nunca se aprobaron y no
están planeados. Sí está planeada una **apertura** al estilo Dedsafio (una imagen y un
título personalizados al iniciar el juego) mediante el mod opcional de cliente; eso no es
un modo de juego Dedsafio.

**¿Habrá un HK5?**
