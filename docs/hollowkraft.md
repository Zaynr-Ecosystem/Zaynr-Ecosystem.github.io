# HollowKraft

**HollowKraft (HK4)** is the next edition of the **Vasijas de Hallownest** community server, built on **Minecraft 26.x**. The project is currently **in development**.

## What is HollowKraft?

HollowKraft starts as a normal survival server: a long-term community world where players build, explore and play together. Everything else is still being defined, and this page will grow as the project takes shape.

## Java and Bedrock, together

HollowKraft plans to welcome Java and Bedrock players in the same world, and **no mods are required to play**. The server targets recent Minecraft versions and will also admit players on older versions where possible.

- **Java players** get the full experience.
- **Bedrock players** are welcome too, with a more limited set of features on their platform.

An optional client mod for Java players is in development: it improves the interface with animations and custom icons. Installing it is never required.

## Status

HollowKraft is in development. There is no release date yet; announcements will be shared as the project advances.
