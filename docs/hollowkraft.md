# HollowKraft

**HollowKraft (HK4)** is the next edition of the **Vasijas de Hallownest** community server, built on **Minecraft 26.x**. The project is **planned and in development**.

!!! info "Status: planned, not released"
    HollowKraft is being planned and built. No release date has been set. Where a point is still open, no decision has been made yet.

## What is HollowKraft?

HollowKraft starts as a normal survival server: a long-term community world where players build, explore and play together. It is not an anarchy server and not a festival server.

## Java and Bedrock, together

HollowKraft plans to welcome Java and Bedrock players in the same world, and **no mods are required to play**. The server targets recent Minecraft versions and will also admit players on older versions where possible.

- **Java players** get the full experience.
- **Bedrock players** are welcome too, with a more limited set of features on their platform.

An optional client mod for Java players is in development. When installed, the custom menu is the default and a toggle returns to the normal Minecraft menu. The mod is also planned to render plugin menus in its own interface, with the normal server menus as fallback. The mod menu is a shortcut; every function is planned to have its own command. Installing it is never required.

The preview art is provisional until an update announces the final art.

## World and player-list compatibility

World rules and detailed settings for both worlds are planned to be managed by **Zelly's Guard**. **Multiverse-Core** is the only external world-management integration planned.

The server plans its own player-list and nameplate system with the same configuration options as **TAB**, rather than depending on the TAB plugin. It covers the header, footer, player-list name, tab order, clan tag and nameplate.

None of these systems are required for players. They are server-side features, not client mods.

## Frequently asked questions

These answers come from the published project plan and documents. When a point has not been decided, the answer says **not decided yet** instead of guessing.

### Release and availability

**When does HK4 open?**
No date has been set. It is not expected this year or next, and the date can move earlier or later. **Not decided yet.**

**Will the server be online 24/7? What are the opening hours?**
The current plan is 24/7 operation. Maintenance windows may still happen. **The exact schedule is not decided yet.**

**How many players will fit?**
The target is 50+ players. The exact cap is not final, and the previous edition's cap is not carried over as a promise.

**What hardware do I need?**
The server is planned to run on basic hardware, not a high-end machine. Exact recommendations are **not decided yet.**

### Game style

**Is HK4 an anarchy server?**
No. HK4 is planned as a normal survival community world, not an anarchy server and not a festival server. The final rule list is **not decided yet.**

**Is it PvP or PvE?**
Two worlds are planned: a PvP world that is semi-peaceful and includes the prank system, and a peaceful world. The exact PvP areas, rules and item transfer are **not decided yet.**

**Will my builds and items be protected?**
Protection is planned through Zelly's Guard, with BlockProt Reloaded for individual blocks. The exact rules and limits are **not decided yet.**

**Will it be harder than vanilla?**
The current plan is hard difficulty. The full rule set is **not decided yet.**

### Worlds, teams and play

**Will there be two worlds, like a peaceful world and a normal world?**
Yes. Two worlds are planned: one PvP world (semi-peaceful, with pranks) and one peaceful world. Their detailed settings are planned to be managed by Zelly's Guard. The names, layout and item transfer are still being defined.

**Can I move items between worlds?**
**Not decided yet.** The two-world layout is planned, but the transfer rules are not final.

**Will there be teams or clans?**
Yes. Clans are planned through Zelly's Nexus. Clan tags can appear in chat and the player list. The exact HK4 rules, clan limits and tag format are **not decided yet.**

**Will there be a shop, a boss, lore or missions?**
**Not decided yet.** These are ideas, not confirmed features.

### Chat, ranks and social

**Is chat global?**
Yes. For now, chat is planned to be global across both the PvP world and the peaceful world.

**What social features are planned?**
Global chat, join and quit messages, achievements and death messages. The chat system also keeps its existing moderation, mentions and item placeholders.

**Do death messages show coordinates?**
They can show the victim's coordinates, but the option is configurable and off by default.

**Will clan tags appear in chat and the player list?**
Yes. Clan tags can appear in chat and in the player list. Both are configurable, and the final tag format is not decided yet.

**Will there be ranks?**
No ranks at launch. Ranks are planned for the future economy. If they are added, their benefits remain cosmetic and do not grant gameplay advantages.

**Will there be a resource pack?**
If a resource pack is offered, it will be optional and opt-in. The first tests are for Java only, and its final contents are still being defined. Players can decline it and keep playing normally.

**Will the player list use TAB and Multiverse-Core?**
The server plans its own player-list and nameplate system with the same configuration options as TAB, rather than depending on the TAB plugin. Multiverse-Core is the only external world-management integration planned. Neither is required for players.

**Do I have to use menus to change chat or player-list settings?**
No. Every chat and player-list setting is planned to have its own command. The settings screens are optional shortcuts.

### Mods, versions and platforms

**Do I need mods to play?**
No. The plan is that the server is fully playable without mods, on Java and Bedrock. An optional client mod for Java players is planned to add a custom menu, a toggle back to the vanilla Minecraft menu, direct join, plugin menus in the mod interface, custom icons and smooth animations. Installing it will never be required.

**Do I have to use menus?**
No. Every function is planned to have its own command, with arguments and tab completion where needed. Menus are optional shortcuts: use them if you like, or use the command directly. No function will be menu-only.

**Is the mod's art final?**
No. The preview art is provisional until an update announces the final art.

**Will the custom projects mod from the previous edition return?**
The current plan does not include it. The only mod in development is the optional interface mod. Any additional mod is **not decided yet.**

**Can Java and Bedrock play together?**
Yes, in the same world. Bedrock compatibility is more limited and has fewer functions than Java.

**Which Minecraft versions are supported?**
HK4 targets recent versions (Minecraft 26.x) and also admits players on older versions where possible. The exact version list is **not decided yet.**

**Can I join from Bedrock 1.26.52.3?**
**Not decided yet.** Bedrock access depends on the server's Geyser and Floodgate setup; no specific build list has been published.

**What do I need to play?**
A Java or Bedrock edition of Minecraft, a recent version where possible, and no mods. The optional Java mod is not a requirement. Exact hardware recommendations are **not decided yet.**

### Economy and events

**Will there be an economy?**
Not at the start. It begins later, when the plugins are ready and look the way they should. If it is used, the default currency name would be "Geo", configurable, and its visuals would need a texture pack.

**Will there be ranks in the economy?**
Ranks are planned for the future economy, not for launch. They remain cosmetic. No rank grants items, currency, claim chunks, priority access or gameplay advantages.

**Is HK4 a Dedsafio edition? Will there be seasonal events?**
No. HK4 is a normal survival server. The seasonal event framework, the "Ruleta de Sorpresas", the lives system and the rescue zone were never approved and are not planned. A Dedsafio-style **opening** (a custom image and title when the game starts) is planned through the optional client mod; that is not a Dedsafio game mode.

### Earlier editions

**Which earlier edition ran on Aternos?**
The public documents do not record the hosting history of every earlier edition. **Not decided yet.**

**Is there going to be an HK5?**
HK4 is the current project. No HK5 has been announced.
