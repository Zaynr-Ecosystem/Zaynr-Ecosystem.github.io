# HollowKraft

**HollowKraft (HK4)** is the next edition of the **Vasijas de Hallownest** community server, built on **Minecraft 26.x**. The project is currently **in development**.

## What is HollowKraft?

HollowKraft starts as a normal survival server: a long-term community world where players build, explore and play together. Everything else is still being defined, and this page will grow as the project takes shape.

## Java and Bedrock, together

HollowKraft plans to welcome Java and Bedrock players in the same world, and **no mods are required to play**. The server targets recent Minecraft versions and will also admit players on older versions where possible.

- **Java players** get the full experience.
- **Bedrock players** are welcome too, with a more limited set of features on their platform.

An optional client mod for Java players is in development: it improves the interface with animations and custom icons. Installing it is never required.

## Status

HollowKraft is in development. There is no release date yet; announcements will be shared as the project advances.

## Frequently asked questions

These answers come from the owner's published plan and the project documents. When a
point has not been decided, the answer says **to be announced** instead of guessing.

### Release and availability

**When does HK4 open?**
There is no date. The owner has said it is not expected this year or next, and that the
date can move earlier or later. **To be announced.**

**Will the server be online 24/7? What are the opening hours?**
**To be announced.**

**How many players will fit?**
**To be announced.** The previous edition's player cap is not carried over as a promise.

### Game style

**Is HK4 an anarchy server?**
No. HK4 is planned as a normal survival community world, not an anarchy server and not a
festival server. The final rule list is **to be announced**.

**Is it PvP or PvE?**
PvP and protections are listed by the owner as possible differentiators, without details.
**To be announced.**

**Will my builds and items be protected?**
Protection is planned through Zelly's Guard, with BlockProt Reloaded for individual
blocks. The exact rules and limits are **to be announced**.

**Will it be harder than vanilla?**
**To be announced.** No difficulty setting has been published.

### Worlds, teams and play

**Will there be two worlds, like a peaceful world and a normal world?**
**To be announced.** No two-world layout has been confirmed.

**Can I move items between worlds?**
**To be announced.**

**Will there be teams or clans?**
**To be announced.** Clans exist as a Zelly's Nexus feature, but using them in HK4 has
not been decided.

**Will there be a shop, a boss, lore or missions?**
**To be announced.** These are ideas, not confirmed features.

### Mods, versions and platforms

**Do I need mods to play?**
No. The server is fully playable without mods, on Java and Bedrock. An optional client
mod for Java players improves the interface with animations and custom icons; installing
it is never required.

**Will the custom projects mod from the previous edition return?**
The current plan does not include it. The only mod in development is the optional
interface mod. Any additional mod is **to be announced**.

**Can Java and Bedrock play together?**
Yes, in the same world. Bedrock compatibility is more limited and has fewer functions
than Java.

**Which Minecraft versions are supported?**
HK4 targets recent versions (Minecraft 26.x) and also admits players on older versions
where possible.

**Can I join from Bedrock 1.26.52.3?**
**To be announced.** Bedrock access depends on the server's Geyser and Floodgate setup;
no specific build list has been published.

**What do I need to play?**
A Java or Bedrock edition of Minecraft, a recent version where possible, and no mods.
The optional Java mod is not a requirement. Exact hardware recommendations are **to be
announced**.

### Economy and events

**Will there be an economy?**
Not at the start. It begins only when the owner gives the plugins the green light: they
work and look the way he wants. If it is used, the default currency name would be "Geo",
configurable, and its visuals would need a texture pack.

**Is HK4 a Dedsafio edition? Will there be seasonal events?**
No. HK4 is a normal survival server. The seasonal event framework, the "Ruleta de
Sorpresas", the lives system and the rescue zone were never approved and are not planned.
A Dedsafio-style **opening** (a custom image and title when the game starts) is planned
through the optional client mod; that is not a Dedsafio game mode.

### Earlier editions

**Which earlier edition ran on Aternos?**
The public documents do not record the hosting history of every earlier edition. **To be
announced.**

**Is there going to be an HK5?**
HK4 is the current project. No HK5 has been announced.
