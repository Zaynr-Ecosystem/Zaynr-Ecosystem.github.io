# About

**Zaynr-Ecosystem** is the home of the Zelly's Guard and Zelly's Nexus Minecraft
server plugins, developed by Zar.

- Organization: [github.com/Zaynr-Ecosystem](https://github.com/Zaynr-Ecosystem)
- The plugin source repositories are private while the projects are in development.
- **BlockProt Reloaded**, the ecosystem's block-locking companion (a fork of
  BlockProt with modern dialog support), is public:
  [github.com/Zaynr-Ecosystem/BlockProt-Reloaded](https://github.com/Zaynr-Ecosystem/BlockProt-Reloaded)
