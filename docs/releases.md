# Releases

Every build published for the ecosystem's projects, and where each one is available.
Release notes ship with each GitHub release of BlockProt Reloaded and live in the
repository under `docs/RELEASE_NOTES/`.

## BlockProt Reloaded

Targets Minecraft 1.21.7 and newer (including 26.x) on Paper, Purpur or Folia, with
Java 21 or newer (Java 25 for 26.x). Published on four platforms:

- [GitHub Releases](https://github.com/Zaynr-Ecosystem/BlockProt-Reloaded/releases)
- [Modrinth](https://modrinth.com/plugin/blockprot-reloaded)
- [Hangar](https://hangar.papermc.io/VictorGugug/BlockProt-Reloaded)
- [CurseForge](https://www.curseforge.com/minecraft/bukkit-plugins/blockprot-reloaded)

not. `tag only` means GitHub carries the version tag without a release entry.

Notes:

- The development builds `1.3.8-BEDev.1`, `1.3.7-BEDev.1` to `1.3.7-BEDev.3` and
  `1.3.3-dev` are available on GitHub only, and `1.3.7-BEDev.3` as a tag without a
  release entry.
- `1.3.0-SNAPSHOT-1`, `1.3.0-SNAPSHOT-2`, `1.2.9-SNAPSHOT` and `1.2.9-dev-2` predate
  the GitHub release flow and are published on Modrinth only.
- Hangar's oldest version is `1.3.1` (it does not carry `1.3.2`); CurseForge's oldest
  is `1.3.2`.
- CurseForge received `1.3.4-Hotfix` and `1.3.2` a few days after the other platforms,
  and holds two files named after `1.3.6`.
- Some platforms use slightly different display strings for the same build (for
  example `1.3.3-RELEASE` appears as `1.3.3` on Modrinth and with a typo on
  CurseForge); the files are identical.
- The older `1.3.8` (Minecraft 1.21.1 to 1.21.6) and `1.3.7` (Minecraft 1.20.5 to
  1.21) builds remain on GitHub Releases for servers that stay on those versions.
