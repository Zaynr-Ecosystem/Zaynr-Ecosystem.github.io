# Zaynr-Ecosystem.github.io

Source of the public documentation site for the Zelly's ecosystem:
**https://zaynr-ecosystem.github.io/**

- Built with [MkDocs Material](https://squidfunk.github.io/mkdocs-material/).
- Deployed to GitHub Pages by `.github/workflows/pages.yml` (Pages source: GitHub Actions).
- Content: public documentation for **Zelly's Guard**, **Zelly's Nexus** and
  **BlockProt Reloaded**.
  Internal development materials are never published here.
- Local preview: `pip install -r requirements.txt`, then `mkdocs serve`.
